Android preview · Google Clock

Let Clock handle the alarm.

This experimental bridge passes a duration from Fitness to Google Clock. It has not been verified with Spotify on your phone.

  1. Install the Fitness Clock Bridge preview on your Android phone.
  2. Open Fitness in Chrome and adjust the web timer to the duration you want.
  3. Tap Google Clock, then confirm the duration in the bridge.
  4. Verify Google Clock shows a running countdown before switching to Spotify.

Download Android preview APK

This is a development-signed test build for Android 8 or newer, not a Play Store release. Android may ask you to allow this installation. The app only requests permission to set alarms/timers; it has no network or workout-data access.

If the handoff did not open

Chrome may have opened this page because the bridge is not installed or the app launch was blocked. No native timer is confirmed. Open Google Clock manually and set the duration. Installing the bridge does not automatically replay the request; return to Fitness and tap Google Clock again.

Two separate timers

The web timer pauses before a handoff attempt to avoid duplicate cues. Its display is not synced with Google Clock. Pause, reset and dismiss the native timer in Google Clock. If you return to web timing, check and stop any native timer first.

First test

Try 15 seconds while watching Clock, then repeat with Spotify foregrounded, then with the screen off. Check your alarm volume, headphones/speaker and Do Not Disturb settings. A correct web countdown on return is not proof of an audible native alarm.
